# Rename plan: The AI Engineer’s Bible to Ground Truth Wiki

Status: **approved and applied** on 2026-11-06. The round trip (`npm run roundtrip`) checks every change listed here against the original through `build/roundtrip-allowlist.json`. Any other difference fails.

## 1. The name

| Where | Before | After | How |
|---|---|---|---|
| Page `<title>`, header brand and its label, `<noscript>` text | The AI Engineer’s Bible | Ground Truth Wiki | `{{site.name}}` tokens in `engine/shell.html`, filled from `site.config.json` |
| Meta description | A course, a reference and a playground for becoming a state-of-the-art AI engineer. | An open, community-reviewed course, reference and playground for AI engineering. | `{{site.description}}` |
| `data/meta.json` `title` | The AI Engineer’s Bible | Ground Truth Wiki | The build fails if it differs from `site.config.json` |
| Engine: document titles, footer, hero title and its label | hardcoded title | `META.title` | 4 small engine edits, each marked `gt:` |
| Engine and style header comments | The AI Engineer's Bible | Ground Truth Wiki | |

In running text the short name **Ground Truth** is used, as the project identity allows.

**Description options.** Two options were proposed for the new description:

- A (chosen): "An open, community-reviewed course, reference and playground for AI engineering."
- B: "The open knowledge base for AI engineers: models, retrieval, agents, evals and production, written and reviewed in public."

Changing it later is a one-line edit of `description` in `site.config.json`.

## 2. The five Bible-flavored names

| Name | Where it appears | Neutral alternative | Decision |
|---|---|---|---|
| Books | the 21 sections: book pages, navigation, boss quizzes, badges, chapter text | none needed | **Kept.** "Book" is neutral. |
| Lexicon | glossary page and its title, search group, navigation, 5 chapters (27 mentions), 2 quiz questions, 1 book blurb | Glossary | **Glossary** for the page, **glossary** in running text ("glossary entry") |
| Genesis | timeline page and its title, navigation, search group, 4 chapters (8 mentions), 1 quiz option | Timeline | **Timeline** for the page, **timeline** in running text ("timeline entries") |
| Commandments | cheat-sheet pages and titles, navigation, search group, workshop section, 4 chapters (23 mentions), 2 quiz questions | Cheat sheets | **Cheat sheets**. A single item, called "a commandment", becomes **a principle**, because the chapter defines it as "a rule plus the reason you can check". |
| Apocrypha | hot-takes page and its title, navigation, 2 chapters (3 mentions) | Debates | **Debates**. "Hot takes" was not used because it already names the callout inside every chapter. |

## 3. What is deliberately kept

- **Internal identifiers:** routes (`#lexicon`, `#genesis`, `#commandments`, `#apocrypha`, `#cmd-*`), chapter ids (`lexicon-guide`, `commandments-guide`, `ai-engineer-role`), widget names (`lexicon`, `commandments`), visual ids (`bible-map`, `commandments-index`, `commandment-compare`), tags, function names, code comments, the `[bible]` console prefix and the storage key `aeb-state-v1`. Old links keep working and readers keep their saved progress.
- **The changelog** (`data/changelog.json`) is a historical record. Its 11 mentions describe what versions 0.9 to 2.0 contained, under the names they had then.
- **The Canon** is not one of the five names. It means a canon of papers, not a religious one.
